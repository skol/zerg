# zerg

Разные мелкие поделки для домашних проектов. Кукбук и полигон идей, собранных для памяти.

## audio

Применяем faster_whisper для транскрибации и диаризации на неограниченных по длинне файлах и боремся с нагревом видеокарты.

Код представлен исключительно в демонстрационных и учебных целях.

Если рассматривать только локальный режим работы, то есть идея решения без нарезки файлов и с более точным контролем самочуствия видеокарты. Но он здесь не предствлен.
